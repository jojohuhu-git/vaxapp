## What's done

1. **S1g — the "Why?" popup no longer claims a stale carried brand applies.** Commit
   `05115f5`. On a row where a brand carried forward (e.g. Pentacel) stopped being valid
   (dose past its licensed range), the row correctly showed "any brand" with the dropdown
   blank, but the Why popup still headed itself "Why Pentacel?" — the explanation body was
   already correct, only the heading was wrong. Root cause:
   `resolveDropdownBrand()` (`ForecastTab.jsx`) falls back to returning the stale brand
   string when no option matches, and that stale value fed the Why button's heading even
   though the dropdown itself renders blank (browser default when no `<option>` matches).
   Fix: track `comboOfferedHere` (does `brandOpts` actually contain this brand) alongside
   the existing `comboSelected`/`displayBrandKey`, and switch the heading to
   `"Why not {brand} here?"` when it doesn't. New test file
   `ForecastTab.comboWhyHeading.test.jsx` (2 tests: heading changes on an invalid row,
   stays normal on a valid one). Live-verified: 5-year-old, Pentacel picked today — the
   6y2mo DTaP booster row's popup now reads "Why not Pentacel here?"; the 5y8mo row (where
   Pentacel is still valid) still reads "Why Pentacel?".
2. **C1 — verified against live CDC sources, NOT a bug.** Both parts of the previously-
   flagged clinical question are correct as built; no code changed.
   - Hib brand mixing (Vaxelis doses 1–2 → Pentacel dose 3 → booster at 12mo): CDC's Pink
     Book Ch. 8 (Haemophilus influenzae),
     <https://www.cdc.gov/pinkbook/hcp/table-of-contents/chapter-8-haemophilus-influenzae.html>,
     quoted live: *"The monovalent Hib conjugate vaccines are interchangeable... If a
     child receives different brands of Hib vaccine at age 2 and 4 months, a 3rd dose of
     any brand should be administered at age 6 months to complete the primary series"* and
     *"DTaP-IPV-Hib-HepB [Vaxelis] should not be used for the booster dose... Any Hib
     conjugate vaccine licensed for a booster dose can be used."* — so mixing brands during
     the primary series, then a mandatory 4th (booster) dose from a different product, is
     exactly what's required.
   - High-risk MenB-4C (Bexsero) dose count: CDC MMWR Dec 2024,
     <https://www.cdc.gov/mmwr/volumes/73/wr/mm7349a3.htm>, quoted live: *"ACIP recommends
     that MenB-4C be administered as a 3-dose series at 0, 1–2, and 6 months to persons
     aged ≥10 years who are at increased risk."* `src/logic/recommendations.js:784-798`
     already implements exactly this, citing the same MMWR.
